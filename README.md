# 粤讲粤掂 · Cantonese Learning Hub

> 从零开始、面向普通话母语者的 AI 辅助粤语学习站 —— 声母韵母声调 · 三周计划 · 分类词汇 · 情景对话 · 录音追踪，一个 HTML 文件全搞定。

**粤语 jyut6 gong2 jyut6 dim6** = 「越讲越好」。这个网站是我用 AI 工具辅助、三周从零学习粤语的产物，也是课程 [LEI1101 · AI as a Tool for Language Learning] 的学习项目成果。

## 🌐 在线使用

**GitHub Pages 地址：见仓库 About 栏的 URL**（或直接打开 `index.html`，全部功能离线可用，无任何外部依赖）。

## 🗣 粤语发音速览（普通话母语者版）

- **声调**：6 调（九声六调），调值 55 / 35 / 33 / 21 / 13 / 22，口诀「三 九 四 零 五 二 七 八 六」
- **入声**：-p / -t / -k 急促收尾（十 sap6 · 一 jat1 · 六 luk6）——普通话者的头号难关
- **长短 a**：aa/a 对立（三 saam1 ≠ 心 sam1）
- **特有声母**：ng-（我 ngo5）、gw-（广 gwong2）；没有 zh/ch/sh、j/q/x

详见 [docs/cantonese-3week-plan.md](docs/cantonese-3week-plan.md)。

## 🔧 技术说明

- **单文件**纯前端（HTML + CSS + JS，~87KB），零依赖、零构建、离线可用
- 语音朗读：Web Speech Synthesis API（`zh-HK` 粤语语音）
- 录音：MediaRecorder API
- 数据持久化：localStorage
- 适配桌面与移动端

## 📖 背景与致谢

本项目为大学课程「AI 辅助语言学习」的个人学习实践：先与 AI 协作完成弱项诊断和学习计划，再执行三周学习，最后用学到的粤语汇报整个学习历程——网站本身既是学习工具，也是学习成果的证明。

粤拼方案采用 **香港语言学学会粤拼（Jyutping）**。
